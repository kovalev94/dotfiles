#+TITLE: ~/.dotfiles

Мои конфигурации Guix System и Guix Home, а также собственные модули и пакеты.
Этот репозиторий также является Guix-каналом с именем =dotfiles=.

* Структура репозитория

- =.guix-channel= :: объявление канала; здесь также объявлена зависимость
  от nonguix (включая данные для проверки подписи), которую Guix обрабатывает
  автоматически.
- =news.txt= :: новости канала в формате =channel-news=; их можно посмотреть
  командой =guix pull --news=.
- =guix-config/= :: корень дерева Scheme-модулей с пространством имён
  =(guix-config ...)=.
  - =channels.scm= :: определения каналов, закреплённые версии каналов,
    серверы подстановок и авторизованные ключи.
  - =packages.scm=, =keyboard.scm=, =ssh.scm=, =substitutes.scm=,
    =doom-modules-packages.scm= :: общие переменные (списки пакетов,
    раскладка клавиатуры, SSH-хосты и т. д.).
  - =packages/= :: собственные определения пакетов, сгруппированные либо
    по назначению (=certs=, =fonts=, =linux=), либо по экосистеме
    (=emacs-xyz=, =golang-xyz=, =python-xyz=).
  - =system/operating-systems/= :: конфигурации операционных систем.
    Общие базовые конфигурации: =base.scm=, =desktop.scm=. Конфигурации
    отдельных машин: =damocles=, =gawain=, =mirage=, =tristan=. Кроме того,
    =guix-installer.scm= — пользовательский установочный ISO-образ на базе
    =installation-os-nonfree= из nonguix.
  - =system/aux-files/= :: вспомогательные файлы, подключаемые к конфигурациям
    через =local-file= (dhcpd.conf, правила iptables и т. д.).
  - =system/images/= :: определения образов.
  - =home/home-environments/= :: home-окружения. Общие базовые конфигурации:
    =base.scm=, =desktop.scm=. Окружения отдельных пользователей: =gino=,
    =lulu=, =schneizel=, =vitaliy-kovalev=.
  - =home/aux-files/= :: дотфайлы программ, разбитые на каталоги-слои:
    =base=, =desktop= и по одному каталогу на пользователя (=gino=, =lulu=,
    =schneizel=, =vitaliy.kovalev=). Подробнее — в следующем разделе.
- =AGENTS.md= :: инструкции для AI-агентов, работающих с кодом.
- =Dream-System.org= :: личная дорожная карта и список задач.

* Дотфайлы

Настройки программ (включая Emacs) находятся в дотфайлах в каталоге
=guix-config/home/aux-files/=, а не в Scheme-модулях. Scheme-код только
указывает, какие слои дотфайлов разворачивать и какие пакеты устанавливать.

- Каждый каталог слоя повторяет структуру домашнего каталога:
  =.config/...=, =.ssh/...=, =.local/...= и т. д.
  - =base= :: минимальный общий слой (=.config/mc=, =.ssh=).
  - =desktop= :: десктопные программы — =.config/alacritty=, =.config/doom=
    (конфигурация Doom Emacs), =.config/dunst=, =.config/exwm=,
    =.config/herbstluftwm=, =.config/nyxt=, =.config/qutebrowser=,
    =.config/rofi=, а также =.exwm= и =.xinitrc-herbst=.
  - каталоги пользователей :: персональные переопределения поверх =base=
    и =desktop=.
- Слои разворачиваются сервисом =home-dotfiles-service-type=; каждое
  home-окружение перечисляет свои слои в поле =directories=, дополняя
  унаследованный список (см. =home/home-environments/desktop.scm= и
  =vitaliy-kovalev.scm=).

* Использование репозитория как канала

Добавьте канал в =channels.scm=
(=~/.config/guix/channels.scm= или =/etc/guix/channels.scm= на установочной
системе):

#+BEGIN_SRC scheme
(channel
 (name 'dotfiles)
 (url "https://github.com/kovalev94/dotfiles.git")
 (branch "main"))
#+END_SRC

Зависимость от nonguix и данные для проверки её подписи объявлены в
=.guix-channel=, поэтому =guix pull= обрабатывает их автоматически.

После каждого пуша в =main= обновляйте локальную копию канала:

#+BEGIN_SRC sh
guix pull
#+END_SRC

Без =guix pull= система и home-окружения будут по-прежнему собираться с
использованием старой версии модулей. О ломающих изменениях объявляется в
=news.txt= — см. =guix pull --news=.

** Проверка локальных изменений перед публикацией

Чтобы проверить изменения без пуша на GitHub, укажите для канала путь к
локальному клону репозитория:

#+BEGIN_SRC scheme
(channel
 (name 'dotfiles)
 (url "/home/user/path/to/dotfiles"))
#+END_SRC

Затем выполните =guix pull=. Обратите внимание: =guix pull= видит только
*закоммиченное* состояние локального репозитория. Создайте локальный коммит,
пушить изменения необязательно. После проверки верните URL GitHub.

* Секреты и ручные действия

Репозиторий НЕ управляет конфиденциальными данными:

- файлы =*.nmconnection= добавляйте вручную после переконфигурирования или
  сборки системы;
- =rclone.conf=, сертификаты и ключи Syncthing добавляйте вручную перед
  переконфигурированием home-окружения;
- Doom Emacs копируйте или устанавливайте вручную после переконфигурирования
  системы или home-окружения; его конфигурация уже находится в дотфайлах
  (=home/aux-files/desktop/.config/doom=). Выполняется переход на ванильный
  Emacs — см. =Dream-System.org=.

* Установка

Чтобы заново развернуть систему с установочного ISO-образа (официального
Guix ISO или собственного из =guix-installer.scm=):

1. Загрузитесь с установочного ISO-образа и настройте сеть.
2. Вручную создайте разделы диска, тома LVM и т. д., создайте файловые
   системы и смонтируйте их в =/mnt=. Базовая система предполагает наличие
   LVM-томов =Guix-Root=, =Guix-Home=, =Guix-Swap= в группе томов =Guix=,
   а также EFI-раздела с меткой =EFI=.
3. Добавьте этот канал в =/etc/guix/channels.scm= на установочной системе
   (см. раздел «Использование репозитория как канала» выше).
4. Обновите каналы:
   #+BEGIN_SRC sh
   guix pull
   #+END_SRC
5. Запустите cow-store для /mnt:
   #+BEGIN_SRC sh
   herd start cow-store /mnt
   #+END_SRC
6. Инициализируйте нужную систему, указав запись operating-system,
   экспортируемую модулем канала:
   #+BEGIN_SRC sh
   guix system init \
       -e '(@ (guix-config system operating-systems tristan) tristan-system)' \
       /mnt
   #+END_SRC
   (Замените =tristan= / =tristan-system= на модуль нужной машины и
   экспортируемую им переменную.)
7. После установки перезагрузитесь в новую систему.
8. Войдите как root и задайте пароли для root и, при необходимости, других
   пользователей.
9. Если определение системы не включает =guix-home-service-type=, настройте
   home-окружение:
   #+BEGIN_SRC sh
   guix home reconfigure \
       -e '(@ (guix-config home home-environments gino) gino-home)'
   #+END_SRC
10. Выполните ручные действия из раздела «Секреты и ручные действия» выше.
